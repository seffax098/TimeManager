- `register` → страница **Регистрация**
- `dashboard` → страница **Анализ дня** с таймером, диаграммой, выбором сайта и таблицей ссылок
- `admin` → страница **Админ-панель** со списком сотрудников и раскрывающейся статистикой
- `profile` → страница **Профиль** с сохранением рабочего стека
- `settings` → страница **Настройки** с CRUD для стека и настройкой рабочего времени

## Структура

- `MainWindow.xaml` — shell приложения и навигация
- `Pages/` — отдельные WPF-страницы
- `Themes/` — light/dark theme resources
- `Services/AppState.cs` — общее состояние приложения
- `Services/DemoDataService.cs` — демо-данные
- `Models/` — модели данных

## Как открыть

1. Открой проект `Front.csproj` в **Visual Studio 2022+** на Windows.
2. Дождись восстановления SDK.
3. Запусти проект как обычное WPF-приложение. (dotnet run)
